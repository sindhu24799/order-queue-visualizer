# 🛒 Order Queue Visualizer

**Live Shopify order processing simulation** with priority queue (min-heap). VIP jumps front, Express behind VIP, Regular queues back. **Smooth animations + pro UI**.

[![Demo](https://github.com/sindhu24799/order-queue-visualizer/blob/main/demo-screenshot.png)](https://sindhu24799.github.io/order-queue-visualizer/)

## ✨ Features
- **3 Priority Levels**: 🔴 VIP (1) | 🟡 Express (2) | 🟢 Regular (3)
- **Live Re-sorting**: Watch heap animations O(log n)
- **Controls**: Add orders, Flash Sale (15 orders), auto-process w/ speed slider
- **Pro UI**: Dark/Light theme, speedometer, pop sounds, stats, LocalStorage
- **PWA Ready**: Offline capable, mobile responsive
